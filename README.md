# Лабораторная работа №3 — Git и ООП

## Описание

Проект демонстрирует работу с Git и инкапсуляцию на примере класса Product.

## Класс Product

Класс описывает товар в магазине.

### Атрибуты

- name — название товара
- price — цена товара
- stock — количество товара на складе
- discount — скидка

### Инварианты

- price > 0
- stock >= 0

### Методы

- get_price() — получить цену
- set_price() — изменить цену
- get_stock() — получить количество товара
- set_stock() — изменить количество товара
- calculate_price_with_vat() — расчёт цены с НДС
- calculate_final_price() — расчёт итоговой цены со скидкой
- restock() — пополнение товара на складе

## Формулы

Цена с НДС = цена × 1.20

Итоговая цена = цена с НДС − скидка
